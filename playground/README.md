# Phase 02 playground

Runnable versions of every snippet in
[`phases/02-javascript-foundations.md`](../phases/02-javascript-foundations.md).

```bash
bun playground/01-basics.js
bun playground/02-loops.js
bun playground/03-async.js
bun playground/04-types.ts
```

Break them on purpose. That is the fastest way to learn what the errors mean.
